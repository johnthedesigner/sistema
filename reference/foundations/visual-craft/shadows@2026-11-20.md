# Designing shadows (Josh W. Comeau)

Source: Josh W. Comeau, "Designing Beautiful Shadows in CSS". https://www.joshwcomeau.com/css/designing-shadows/

- Two purposes for shadow: raise the prominence of a specific element (elevation draws attention; closer things are noticed first) and make the interface feel tactile.
- **One light source:** shadows created one at a time end up mismatched and read as "blurry borders". Every shadow on a page shares the same ratio of horizontal to vertical offset.
- As an element rises: offset grows, blur grows, and opacity falls.
- **Layering:** stack several shadows with increasing offset and blur for a softer, more realistic result than one shadow.
- **Color-matched shadows:** transparent black over a colored background desaturates it; a shadow tinted to the background's hue, darker and less saturated, looks more natural. Too saturated and it looks like a glow.
- In a design system: define a small set of elevation shadows as tokens built from the same light source and a shadow color per surface.
