# Reference notes (internal)

These are working notes on the design systems, standards, research, and agent skills Sistema learned from. They were gathered to write Sistema's guides, and many are close summaries of their sources.

They are not Sistema content and not meant for end users. The site doesn't serve them, and plays and guides don't link to them. Sistema's published guidance is in `content/`. Credits for every source, with licensing, are in `content/sources.yaml` and on the site's Sources page.
