# Spacing

**Source:** `tailwindcss.com/docs/padding` (and the spacing namespace in `tailwindcss.com/docs/theme`)

Tailwind v4 has one spacing base, `--spacing` (default 0.25rem, 4px). Every numeric spacing utility is a multiple of it: `p-4` is `calc(var(--spacing) * 4)` = 16px, `p-0.5` is 2px, `p-px` is 1px. Any integer (and quarter/half values) works, so the scale is open-ended rather than a fixed list.

- The same base drives padding, margin, gap, width, height, inset, and sizing utilities.
- Changing `--spacing` (for example to `1px`) rescales every spacing utility at once.
- Named spacing values can be added with `--spacing-<name>` to create utilities such as `p-<name>`.
- Arbitrary values: `p-[5px]`, `p-(--my-padding)`.

**Implication for naming:** a token named by its multiple of the base (`space.4` = 16px on a 4px base) means the same as the Tailwind utility number (`p-4`).
