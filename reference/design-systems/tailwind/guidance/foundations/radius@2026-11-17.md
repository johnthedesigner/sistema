# Border radius

**Source:** `tailwindcss.com/docs/border-radius`

T-shirt named radius scale, driven by `--radius-*` theme variables:

| Utility | Value |
|---|---|
| `rounded-none` | 0 |
| `rounded-xs` | 0.125rem (2px) |
| `rounded-sm` | 0.25rem (4px) |
| `rounded-md` | 0.375rem (6px) |
| `rounded-lg` | 0.5rem (8px) |
| `rounded-xl` | 0.75rem (12px) |
| `rounded-2xl` | 1rem (16px) |
| `rounded-3xl` | 1.5rem (24px) |
| `rounded-4xl` | 2rem (32px) |
| `rounded-full` | `calc(infinity * 1px)` |

Side and corner variants (`rounded-t-*`, `rounded-tl-*`, logical `rounded-s-*`/`rounded-e-*`), arbitrary values (`rounded-[2vw]`), and custom steps (`--radius-5xl: 3rem` creates `rounded-5xl`) are supported.
