# Theming

**Source:** `ui.shadcn.com/docs/theming` (code blocks from `shadcn-ui/ui` `apps/v4/content/docs/(root)/theming.mdx`)

## Model

shadcn/ui themes through CSS variables holding semantic tokens. Components use the tokens by default, so changing the variables restyles the app without editing component classes. The tokens are declared under `:root` and `.dark`, and exposed to Tailwind with `@theme inline`, which produces utilities such as `bg-background`, `text-foreground`, `border-border`, and `ring-ring`. CSS variables are the default (`tailwind.cssVariables: true` in `components.json`); the CLI can instead generate components with inline Tailwind color utilities, an install-time choice.

Dark mode overrides the same tokens inside a `.dark` selector.

## Token convention: surface and foreground pairs

Each surface token pairs with a `-foreground` token for the text and icons on it. The surface token drops the "background" suffix: `primary` pairs with `primary-foreground`, and a component with `bg-primary text-primary-foreground` gets both.

| Token | Controls | Used by |
|---|---|---|
| `background` / `foreground` | App background and default text | Page shell and sections |
| `card` / `card-foreground` | Raised surfaces | Cards, dashboard and settings panels |
| `popover` / `popover-foreground` | Floating surfaces | Popovers, dropdown and context menus |
| `primary` / `primary-foreground` | High-emphasis actions, brand surfaces | Default buttons, selected states, badges |
| `secondary` / `secondary-foreground` | Lower-emphasis filled actions | Secondary buttons and badges |
| `muted` / `muted-foreground` | Subtle surfaces, lower-emphasis text | Descriptions, placeholders, helper text |
| `accent` / `accent-foreground` | Hover, focus, active surfaces | Ghost buttons, menu highlights, hovered rows |
| `destructive` | Destructive actions, errors | Destructive buttons, invalid states |
| `border` | Default borders and separators | Cards, menus, tables |
| `input` | Form control borders | Inputs, textareas, selects |
| `ring` | Focus rings | All focusable controls |
| `chart-1` … `chart-5` | Default chart palette | Charts |
| `sidebar`, `sidebar-primary`, `sidebar-accent` (+ `-foreground`), `sidebar-border`, `sidebar-ring` | Sidebar-specific versions of the above | The Sidebar component |
| `radius` | Base corner radius | Derived `radius-*` tokens |

New tokens follow the same pattern: declare `--warning` and `--warning-foreground` under `:root` and `.dark`, map them in `@theme inline`, and `bg-warning text-warning-foreground` becomes available.

Base colors for generated themes: Neutral, Stone, Zinc, Mauve, Olive, Mist, Taupe.

## Radius: one base, derived steps

`--radius` is the single source; the scale is derived from it:

```
--radius-sm:  calc(var(--radius) * 0.6)
--radius-md:  calc(var(--radius) * 0.8)
--radius-lg:  var(--radius)
--radius-xl:  calc(var(--radius) * 1.4)
--radius-2xl: calc(var(--radius) * 1.8)
--radius-3xl: calc(var(--radius) * 2.2)
--radius-4xl: calc(var(--radius) * 2.6)
```

`radius-lg` equals the base. Changing `--radius` rescales every step. The names reuse Tailwind's radius names, so `rounded-lg` follows the theme.
