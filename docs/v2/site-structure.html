Sistema site structure

Four places to go, one prompt box that every entry point shares, and the pages and URLs behind them. The written version is docs/v2/site-structure.md.

1 · The prompt box

Choose what you want to do, then copy the prompt

This one works. Try the suggestions, edit the text, and copy. The headline is the working one from the narrative.

Firm foundations for AI-built apps. More room to design.
Paste into Claude Code, Cursor, or another coding agent, in your project folder.
What do you want to work on?
  • The text in square brackets is for you to fill in. The box is editable, so the copied prompt says what you want.
  • The button reads "Copy prompt" with a copy icon. An arrow would suggest the message gets sent.
  • The same box appears on the "Work on my system" page with only the second row, and on workflow and play pages with no suggestions.
  • Later (V4), a toggle above the box switches between Prompt and MCP server.
