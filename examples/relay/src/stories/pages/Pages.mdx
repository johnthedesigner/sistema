# Page examples

Two realistic Relay screens, composed from the real components and tokens so the system can be judged at the size of a screen.

- **Today's board** (story: Pages / Page examples / Today's board; in the app: `/sistema-review/pages/board`): the job that needs a tech now on the featured surface, a warning, today's numbers, and the jobs table.
- **Job detail** (story: Pages / Page examples / Job detail; in the app: `/sistema-review/pages/job`): status and next step on the featured surface, visit, notes for the tech, customer, activity history, and the reassign and cancel dialogs.

Use the Theme toolbar to see both themes. Open the stories full screen for the real width.

## Known gaps

Things these screens needed that the system doesn't have yet, composed from tokens rather than given new styles. Each can become a component through "add a component":

featured panel, metric strip, sidebar navigation (and a phone version), page header, toast, tabs or segmented control, input with an icon, text link with its focus ring, description list, a responsive table pattern below 768px, an empty state, and width tokens for panes and columns.
