# Tokens

Relay's tokens are written once in `tokens/src/` and compiled with `npm run tokens`. Every value on this page is read at runtime from the compiled CSS custom properties, so it follows the Theme toolbar and any recompile. Code uses the role tokens only; the ramps are the primitive tier and are never used directly.
