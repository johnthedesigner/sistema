## Design system (Sistema)
This project follows Sistema. "Start a design system" is finished. For later design system work, fetch the URL in sistema.json "continue". "Build the patterns" is in progress: the core components in src/components/ui/
are waiting for approval at /sistema-review/components. Tokens live in tokens/src/
(compile with `npm run tokens`); DESIGN.md and VOICE_AND_TONE.md describe how to
use them; shadcn/ui's variables map to the role tokens in
src/styles/shadcn-theme.css. Before any design system work (tokens, colors, type,
components, DESIGN.md), read sistema.json and fetch the URL in its "continue"
field, then follow it.
