## Design system (Sistema)
This project follows Sistema. "Build the patterns" is finished. For later design system work, fetch the URL in sistema.json "continue". Tokens live in tokens/src/ (compile with `npm run tokens`); DESIGN.md and
VOICE_AND_TONE.md describe how to use them; the core components are in
src/components/ui/ (shadcn/ui on Base UI, variables mapped in
src/styles/shadcn-theme.css). The system reference is Storybook: `npm run
storybook` (port 6006), `npm run build-storybook` (to storybook-static/),
`npm run test:storybook`. Before any design system work (tokens, colors, type,
components, DESIGN.md), read sistema.json and fetch the URL in its "continue"
field, then follow it.
