## Design system (Sistema)
This project's design system follows Sistema. The "Start a design system"
workflow is finished: tokens live in tokens/src/ (compile with `npm run tokens`),
and DESIGN.md and VOICE_AND_TONE.md describe how to use them. Before any later
design system work (tokens, colors, type, components, DESIGN.md), read
sistema.json and fetch the URL in its "continue" field, then follow it.
