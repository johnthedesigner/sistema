Layout aliases

layout-page-gutter {space.6}: Horizontal padding of the app frame and page containers (24px): enough to separate content from the window edge without spending width a wide table needs.
layout-section-gap {space.4}: Gap between panels and page regions, e.g. job board and detail pane (16px).
layout-panel-padding {space.3}: Inner padding of panels, cards, popovers, and dialogs (12px).
layout-stack-gap {space.3}: Vertical gap between form fields and between stacked blocks inside a panel (12px).
layout-component-gap {space.2}: Gap between related controls: buttons in a toolbar, filters in a filter bar, fields in one form row (8px).
layout-field-gap {space.1}: Gap between a label and its input, or an icon and its text (4px).
layout-cell-padding-x {space.2}: Horizontal padding inside table cells and list rows (8px).
layout-control-height {space.8}: Height of buttons, inputs, selects, and toolbar controls (32px); above the WCAG 2.2 AA 24px target minimum.
layout-row-height {space.8}: Table and list row height (32px), equal to control-height so filter bars line up with the rows below.

Approved but not yet tokenized

No play was skipped, so every category in the direction has tokens. These approved details can't be expressed as tokens and live in DESIGN.md instead:

  • Uppercase overline: the overline role is set in uppercase. DTCG type tokens have no text-transform, so components must add it (DESIGN.md Typography).
  • Mono face for data: Tailwind's text-data-mono utility carries size, line height, weight, and tracking but not the font family; pair it with font-mono.
  • Status chips: dot plus word plus container (from the preview) is a component pattern; the final status list is set when the status chip is built (patterns workflow).
