# Decisions

## Positioning

Relay is a dispatch dashboard for a small field-service company doing HVAC and plumbing work. Five to twenty dispatchers and office staff use it on desktop all day to assign jobs to technicians, track each job's status through the day, and handle incoming customer requests. The interface is dense: tables, filters, status lists, and forms, scanned and updated constantly, so legibility at small sizes, fast status recognition, and low visual fatigue over an eight-hour shift matter more than first impressions. It sits firmly on the utilitarian side: clarity and speed come before personality, but it should not look like a generic admin template; a restrained, specific character is welcome where it costs nothing in speed. It is web only, light and dark themes with light primary, built by one small team on Next.js, React, Tailwind CSS v4, and shadcn/ui, with roughly 20 to 40 components expected. It must meet WCAG 2.2 AA. There is no existing brand, logo, or color to honor, and nothing to avoid.

Inferred, not asked: stack details (Next.js 15.5, React 19.1, Tailwind v4 via @tailwindcss/postcss) read from package.json; the create-next-app placeholder colors (#ffffff / #171717) and Geist fonts in globals.css/layout.tsx treated as scaffold defaults, not brand decisions, so color is not routed to color.map-existing; "low visual fatigue over a full shift" inferred from all-day desktop use.
