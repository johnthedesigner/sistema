## Why

Existing work carries decisions you may not remember making, and code that depends on them. Replacing it silently breaks things and erases those decisions. Seeing the options side by side lets you choose with the consequences in view.

## When you'd choose otherwise

You want a clean slate.

## If you override it

Say so once. It's logged, and the agent treats existing values as references rather than constraints.
