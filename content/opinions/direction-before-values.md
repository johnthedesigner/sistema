## Why

Values chosen without a direction are arbitrary. They get argued about one at a time, and they rarely add up to a coherent product. A direction makes each later choice easier to judge.

## When you'd choose otherwise

You're adopting an existing brand whose values are fixed. The direction already exists, so the assessment step records those values as decided.

## If you override it

Values come first and the direction is written to fit them. The style preview still gets built, so you can see whether they hang together.
